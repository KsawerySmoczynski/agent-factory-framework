# Goal

**Self-modifying agent toolchains as first-class engineering artifacts.** Rather than engineering software directly, you engineer the *meta-process* — the agent configuration, prompt chains, verification pipelines, and context protocols that produce software. 

Proof-carrying code as the replacement for code review. The hard part shifts to writing specifications precise enough to prove against — and that's where engineering knowledge transforms rather than disappears.

## Philosophy

Architecture is the product; code is ephemeral. The durable engineering artifact is the specification — interface graphs, invariant declarations, contract test suites, module manifests. Implementations are regenerable from specs. Version control tracks *specification changes*; code is a derived artifact.
